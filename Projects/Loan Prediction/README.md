# Loan Approval Prediction💸

## Objective
Predict loan approval status using applicant and financial features.

## Steps Covered
- Data cleaning & EDA
- Feature engineering
- Logistic Regression baseline
- Random Forest model
- Threshold tuning for risk-aware decisions

## Key Insight
Credit history is the strongest driver of loan approval.
The final model uses a 0.60 decision threshold to reduce false approvals.

## Final Model
Random Forest Classifier with tuned decision threshold.
